# Stay Connect — first real lifecycle evidence

Use this only when a real authorized hotel workflow naturally occurs. Do not create a booking, guest, payment or housekeeping event to fill this checklist.

- [ ] Direct booking or authorized front-desk reservation recorded
- [ ] Reservation visible in Sena
- [ ] Correct inventory reduction confirmed
- [ ] Guest record created or linked correctly
- [ ] Confirmation behavior recorded
- [ ] Arrival visible
- [ ] Check-in completed
- [ ] Room became occupied
- [ ] Payment recorded
- [ ] Payment reconciled with the reservation and invoice
- [ ] Checkout completed
- [ ] Room became dirty and required turnover
- [ ] Housekeeping completed
- [ ] Room became clean and available
- [ ] Owner dashboard totals reflected the lifecycle
- [ ] Reports agreed with the underlying reservation and payment records

For every item, retain the reservation reference, event time, staff role, browser/device and a screenshot or safe log reference. Do not include card data, credentials or unnecessary guest personal information.
